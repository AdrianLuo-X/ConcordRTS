# 扩展兼容验证模组

这是用于验证扩展功能的自编示例模组，使用本机提供的尤里的复仇资源，不改变正常游戏配置。

运行 `prepare.ps1 -Launch`，随后选择盟军遭遇战。脚本从本机原规则生成独立验证目录，并将该目录作为本次启动的模组。

- 灰熊坦克有 300 点轻甲护盾，选中时生命条上方显示蓝色护盾条；破盾后恢复，未破盾时缓慢自愈。
- 美国大兵带永久附加效果：火力 ×1.5、速度 ×1.25，附着原版循环光环动画。
- 使用 AP 弹头的攻击会暂时降低目标速度、延长射击间隔，并显示附着动画。
- 盟军电厂提供额外的两种伞兵和间谍飞机支援。各支援仍遵守正常充能和原有使用规则。

支持范围以源码实现与专项测试为准。示例不承诺兼容任意第三方模组。
